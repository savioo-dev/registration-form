# Registration Form

Projeto desenvolvido durante meus estudos de HTML e CSS na certificação **Responsive Web Design** da freeCodeCamp.

## Sobre o projeto

Formulário de cadastro com campos para informações pessoais, e-mail, senha, tipo de conta, foto de perfil, idade e biografia.

## Tecnologias utilizadas

- HTML5
- CSS3

## O que pratiquei

- Estruturação de páginas HTML
- Criação de formulários
- Tipos de campos e atributos de validação
- Estilização com CSS
- Organização de arquivos de um projeto web
